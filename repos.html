Statistics and data processing

statisticalc

Header-only C++20 running statistics: a rolling (optionally unlimited) window of observations with descriptive statistics maintained by recursion formulas and inferential statistics (t-test, variance test, and their two-sample counterparts) computed on top of them.

  • https://github.com/pbosetti/statisticalc

SlidingDFT

SlidingDFT is a small C++20 library that maintains a sliding discrete Fourier transform over a fixed-size window of real-valued samples. Updating the DFT is done in O(1) time, and the library is designed to be used in real-time applications.

  • https://github.com/pbosetti/SlidingDFT

kalman

A fast, header-only C++20 library for Kalman filtering — built on Eigen, with zero hand-rolled linear algebra and zero install friction.

Define a state vector, a system model, and a measurement model, and you have a working state estimator in a few dozen lines. The library does the heavy lifting (sigma points, Jacobian propagation, square-root covariance updates) behind a small, strongly-typed interface.

  • https://github.com/pbosetti/kalman

goertzel

goertzel is a small multi-language package around the Goertzel algorithm. The Goertzel algorithm is a digital signal processing technique for efficiently evaluating individual terms of the discrete Fourier transform (DFT). It is particularly useful for detecting specific frequency components in a signal, making it suitable for applications such as tone detection and spectral analysis.

  • https://github.com/pbosetti/goertzel

adas.utils (R package)

The goal of adas.utils is to provide some utility functions to be used in the course Analysis of Data and Statistics (ADAS).

  • https://github.com/pbosetti/adas.utils

mdbplyr (R package)

mdbplyr is the MongoDB version of dbplyr, the package for interacting with SQL databases. It provides a disciplined dplyr-style interface for read-only analytical MongoDB queries. Queries stay lazy, compile into MongoDB aggregation pipelines, and only execute at collect().

  • https://github.com/pbosetti/mdbplyr

Arduino

The followings are my Arduino-related repositories, mainly for educational purposes.

  • https://github.com/pbosetti/ArduinoRpc: Arduino RPC library for Arduino boards and ESP32/ESP8266
  • https://github.com/pbosetti/ArduinoDriver: Turn a compatible Arduino board to a USB-class I/O device, plus its companion userland driver. Acquire signals at up to 30 kHz!

Utilities

  • https://github.com/pbosetti/SigGen: Signal generator class.
  • https://github.com/pbosetti/Expressionist: A small C++20 library for parsing and evaluating mathematical expressions within a JSON object.
  • https://github.com/pbosetti/gv2fsm: A small C++20 library and CLI tool for converting a Graphviz graph into a finite state machine (FSM) C++ class.
  • https://github.com/pbosetti/pugg: A C++ class for implementing plugins that can be loaded at runtime via dlopen.
  • https://github.com/pbosetti/EmbedR: A small C++20 library for embedding R scripts into a C++ program, with automatic data exchange between the two languages.
  • https://github.com/pbosetti/cppy3: Minimalistic library for embedding CPython 3.x into a C++ application. Lightweight, simple, and clean alternative to heavy boost.python. No additional dependencies. Cross-platform – Linux, macOS, and Windows are supported.
